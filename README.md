# Beep Alert

Android app with a draggable vertical fader in the middle of the screen (level 0–10), like a volume control. Press **Start** to play a repeating beep; the higher the level, the louder the beep.

## Get the APK
GitHub → **Actions** → **Build APK** → latest run → download `beep-alert-apk`. Unzip and install `app-debug.apk` on the phone (allow "Install unknown apps").

## Build locally
Requires Android SDK (API 34) and Gradle 8.14: `gradle assembleDebug`
